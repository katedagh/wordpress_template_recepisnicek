# Custom WordPress Theme

A custom WordPress classic theme built with PHP, HTML, CSS and JavaScript.
[Live Website](https://www.recepisnicek.cz/)


## About the Project

This project is a custom WordPress theme created to explore WordPress theme development and build a website with a personalized design and functionality.
The theme uses PHP templates and standard WordPress theme structure to display dynamic website content.


## Features

- Custom website layout and styling
- Custom header and footer
- Separate header and footer navigation menus
- PHP-based WordPress templates
- Custom CSS styling
- JavaScript interactions
- Dynamic seasonal animations


## Technologies

- HTML5
- CSS3
- PHP
- JavaScript
- WordPress
